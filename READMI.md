# My First Web Page

A simple and responsive landing page built using HTML, CSS, and JavaScript.

## Features

- **Header & Navigation:** Links to Home, Features, and Contact sections.
- **Hero Section:** Displays a welcome message and a Get Started button.
- **Feature Cards:** Highlights Fast, Simple, and Responsive features.
- **Interactive Button:** Uses JavaScript to display a message when clicked.
- **Responsive Design:** Designed to work on mobile and desktop screens.
- **Footer:** Displays copyright information.

## Technologies Used

- HTML5 — Page structure
- CSS3 — Styling and layout
- JavaScript — Interactive functionality

## Project Structure

```text
TaskFlow/
```

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Click **Get Started** to test the button interaction.

## Customization

- Edit `index.html` to change the content.
- Edit `style.css` to customize the design.
- Edit `script.js` to modify button behavior.
